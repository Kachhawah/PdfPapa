# Security Policy - PdfPapa 🛡️

## Reporting a Vulnerability

We take the security of **PdfPapa** and user document privacy very seriously. We appreciate your efforts to responsibly disclose any potential vulnerabilities.

### How to Report

You can report security vulnerabilities through:

1. **GitHub Security Advisory**:
   - Navigate to the [Security Tab](https://github.com/Kachhawah/PdfPapa/security) in our repository.
   - Click on "Report a vulnerability".
   - Provide a detailed description of the vulnerability.

2. **Direct Contact**:
   - Email: `shaurabhsinghkachhawah@gmail.com`
   - Please include as much information as possible about the vulnerability and steps to reproduce.

### What to Include

When reporting a vulnerability, please provide:
- A clear description of the vulnerability
- Steps to reproduce the issue
- Any potential impact on client-side or server processing
- Suggested fixes or mitigations (if available)

### Response Time

We aim to acknowledge receipt of vulnerability reports within 48 hours.
